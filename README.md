# Faith — All School Uniforms & Protective Clothing

This is Faith's static storefront. Product names, catalogue prices and business contact details are shown in index.html. Cropped catalogue product photos are in images/products.

## Publish

GitHub Pages is configured with the workflow in .github/workflows/pages.yml. In this repository, open Settings > Pages and choose GitHub Actions as the build and deployment source. The site will then publish at https://bigstepparack3s-ops.github.io/faith-school-uniforms/. Each push to main triggers a new deployment.

## Make updates

- Edit index.html for the business copy, the products array, prices, contact details or map location.
- Replace or add photos in images/products using each product ID as the filename, such as sun-hats.jpg.
- Commit the changes to main. GitHub Actions will publish them automatically.

Orders and payments are handled directly with Faith through WhatsApp or email. This website does not collect payments. Prices are in US dollars as listed in the supplied catalogue.
