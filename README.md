# Faith — All School Uniforms & Protective Clothing

A static storefront. Product cards and cropped catalogue photos are in images/products. The whole site is served from this folder. Orders and payment arrangements go directly through Faith's WhatsApp or email. The site does not process payments.

## Publish on GitHub Pages

1. Create a GitHub repository for this site and push these files to the main branch.
2. In the repository, open Settings > Pages and set the build and deployment source to GitHub Actions.
3. The included workflow publishes the site after each push to main. GitHub Pages assigns a public github.io address. A custom domain can be connected later if you own one.

## Update the site

- Edit index.html for business copy, product names and prices, contact details and the map link. The catalogue is in the products array near the end of the file.
- Replace or add product photos in images/products; use the matching product ID as the image filename (for example, sun-hats.jpg).
- Commit and push to main; GitHub Pages publishes the update automatically.

Prices are shown in US dollars as listed in Faith's supplied WhatsApp catalogue.
